How the numbers were made

Every regular-season game from 2023-24 (the PWHL's first season) to 2025-26: 282 PWHL games and 3,936 NHL games.

Data

Play-by-play and schedules come from the PWHL (HockeyTech) and NHL APIs, through the fastRhockey R package. Rinks are drawn with sportyR. Both leagues play on NHL-sized rinks, so one rink template fits both.

In a few PWHL games, one team's shots for a whole period are recorded at the wrong end of the rink. They have normal shooting percentages, so they are mis-recorded rather than real long-range shots, and they are flipped back.

Definitions

  • Shots means shots on goal (saves plus goals). The PWHL doesn't publish missed or blocked shots, so this is the fairest measure both leagues share.
  • Rates use regulation time only, so every game counts for exactly 60 minutes.
  • Shot distance is measured from the centre of the net, with the goal line 89 feet from centre ice:
    \[ d = \sqrt{(89 - x)^2 + y^2} \]
  • Shot angle is degrees off the line straight out from the net, so 0° is dead centre and 90° is level with the goal line:
    \[ \theta = \arctan\!\left(\frac{|y|}{89 - x}\right) \]
    Wide-angle shots tend to be taken close to the net, so shooting % by angle is compared within distance bands.
  • Shot types are grouped so they mean the same thing in both leagues. Wrist and snap shots are combined because scorers split them inconsistently. Tips and deflections are combined because the PWHL only records "tip". About 30% of PWHL shots have no recorded type (46% in 2023-24, 21% in 2025-26). Those shots go in more often than PWHL wrist shots, so they aren't a random sample, and they're left out of shot-type comparisons rather than guessed at.

Shot quality: PWHL shots at NHL rates

To test whether PWHL teams take worse shots, a logistic regression is fit on NHL shots only, using distance, distance squared, angle and (optionally) shot type:

\[ P(\text{goal}) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 d + \beta_2 d^2 + \beta_3 \theta + \beta_{\text{type}})}} \]

Its predictions are then averaged over PWHL shots. The result answers one question: if these exact shots went in as often as similar NHL shots, what would PWHL shooting % be? The answer is 10.8%, slightly above the NHL's own actual rate of 10.3%.

Goalies: goals saved above expected

The same model form is fit separately for each league, so each goalie is compared with their own league. A shot's expected-goal value (xG) is its predicted probability of going in. For each goalie:

\[ \text{GSAx} = \sum \text{xG against} - \text{goals against} \]

It is shown per 100 shots so goalies with different workloads share a scale, for goalies who faced at least 500 shots. Adding angle and type barely changes the rankings compared with a distance-only model (correlation above 0.98 in both leagues).

Shooters vs goalies

Each league gets one logistic model with shot distance, angle and type, plus a random effect for every shooter \(s\) and every goalie \(g\):

\[ \operatorname{logit} P(\text{goal}) = \beta_0 + \beta_1 d + \beta_2 d^2 + \beta_3 \theta + \beta_{\text{type}} + u_s + v_g \]
\[ u_s \sim N(0, \sigma_u^2), \qquad v_g \sim N(0, \sigma_v^2) \]

Random effects are estimated as deviations from the league average and pulled toward zero for players with few shots. The spreads \(\sigma_u\) and \(\sigma_v\) are converted from log-odds to percentage points at the league's average shooting %, \(\bar p\), using \(100\,\bar p(1-\bar p)\,\sigma\).

Result: shooters vary by about 1.9 points in both leagues; goalies by 0.5 (NHL) and 0.6 (PWHL). Fit with lme4::glmer.

What this can't do: it can't split the league-wide gap into shooting and goaltending. Adding a constant to every shooter and subtracting it from every goalie gives identical predictions, so the data can't tell them apart. That split would need an outside benchmark.

Limits

  • Sample size. 282 PWHL games vs 3,936 NHL games. PWHL estimates are much less precise; charts show 95% confidence intervals where relevant.
  • What the models leave out. Rebounds, rush chances, screens and passes before the shot aren't in the data for both leagues. Shooter effects may partly reflect them, so treat expected goals as a rough adjustment.
  • Data revisions. The NHL feed is occasionally revised, so a fresh download can shift results slightly.

Reproduce

Install the packages:

install.packages(c("tidyverse", "fastRhockey", "sportyR", "hexbin", "lme4"))

Then open the project folder in Positron or RStudio and run source("run_all.R"). The first run downloads about three seasons of NHL play-by-play and takes a few minutes. Charts are saved to figures/ and summary tables to output/; this site reads the charts directly.
